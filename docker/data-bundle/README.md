# Комплект данных, вшиваемый в образ

Положите сюда `scanner-data-<дата>.tar` перед `docker compose build`, если
нужен образ «всё в одном» (например, для переноса в закрытый контур через
`docker save`). Файл попадёт в образ в `/app/docker/data-bundle/`, и при первом
старте entrypoint загрузит его так же, как комплект из `./data/bundle/`.

Обычный путь — не вшивать, а класть комплект в `./data/bundle/`: образ не растёт
на сотни мегабайт, а свежий комплект не требует пересборки. Подробно —
docs/INSTALL.md, раздел «Комплект данных уязвимостей».
