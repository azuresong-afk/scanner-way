# Документация Scanner

Комплект эксплуатационной документации сетевого сканера уязвимостей Scanner.
Состав и деление по читателям — как у коммерческих сканеров (MaxPatrol VM,
Tenable, Qualys, Rapid7): общее описание, установка, администрирование,
работа оператора, справочник и сведения о выпусках.

> Scanner предназначен только для авторизованного тестирования защищённости
> по договору. Сканируются только адреса из allowlist проекта; каждое действие
> пишется в журнал аудита.

## Соглашения

- **Проект** — объект работ в интерфейсе: договор с заказчиком, его allowlist,
  учётные записи и активы. Юридический документ по-прежнему называется
  договором (поле «Номер договора»). В API и CLI проект — `engagement`.
- **Прогон** — один запуск сканирования (в API — `scan run`).
- Названия разделов интерфейса даны в кавычках: «Сканирование», «Активы».
- Команды CLI выполняются из каталога установки и внутри контейнера:
  `docker compose exec app scanner …`.
- Адреса API даны относительно корня API. Через веб-интерфейс тот же API
  доступен с префиксом `/api` (`http://<сервер>:8080/api/runs/1`).
- Порты по умолчанию: веб 8080, API 8000 (только `127.0.0.1`), PostgreSQL 5432
  (только `127.0.0.1`). Если в `.env` заданы другие, подставляйте свои.

Документация описывает версию из ветки `main` на дату, указанную в
[сведениях о выпусках](06-release-notes.md).
